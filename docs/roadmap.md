# Roadmap

Version targets are intentional, not calendar promises.

## v0.1.0 — MVP (shipped)

- [x] Script editor + settings
- [x] Local autosave
- [x] Camera record + teleprompter scroll
- [x] Review / download / share
- [x] PWA installability
- [x] Docs + SemVer changelog

## v0.2.0 — Usability

- [ ] Multiple saved scripts (IndexedDB library)
- [ ] Landscape-first recorder layout polish
- [ ] Keep-awake while recording (`Wake Lock` API when available)
- [ ] Better iOS mime / download naming edge cases
- [ ] Haptic / large tap targets audit on small phones

## v0.3.0 — Teleprompter power features

- [ ] Marker / section jump in script
- [ ] Remote control from a second device (same Wi-Fi / QR pair)
- [ ] Optional mirrored glass preset pack
- [ ] Reading-line cue (horizontal focus band)

## v1.0.0 — Production-ready

- [ ] Thorough device QA matrix (iOS Safari, Android Chrome, desktop)
- [ ] Accessibility pass (screen reader labels, reduced motion)
- [ ] Error telemetry opt-in (privacy-preserving)
- [ ] Stable branding + store-quality install experience
- [ ] Optional: canvas burn-in recording mode

## Ideas backlog (unscheduled)

- Voice-follow scrolling (`SpeechRecognition`)
- Timecode overlays
- Multi-language UI
- Export settings presets
- Capacitor / native wrapper only if App Store distribution becomes a hard requirement
